2. SCHEMA MARKUP (JSON-LD — inject via <script type="application/ld+json">)
   Implement ALL of the following schemas:
   
   a) Organization schema:
      {
        "@type": "Organization",
        "name": "[Brand Name]",
        "url": "https://yourdomain.com",
        "logo": "...",
        "sameAs": [
          "https://www.facebook.com/...",
          "https://www.instagram.com/...",
          "https://www.tripadvisor.com/...",
          "https://en.wikipedia.org/wiki/..." (add when available)
        ]
      }

   b) LodgingBusiness / Resort schema (Google rich result eligible):
      {
        "@type": "LodgingBusiness",
        "name": "...",
        "description": "Eco retreat in Vietnam offering sustainable lodges...",
        "address": { "@type": "PostalAddress", "addressCountry": "VN", ... },
        "geo": { "@type": "GeoCoordinates", "latitude": ..., "longitude": ... },
        "starRating": { "@type": "Rating", "ratingValue": "5" },
        "amenityFeature": ["Organic restaurant", "Yoga pavilion", "Forest trails"],
        "priceRange": "$$$",
        "checkinTime": "14:00",
        "checkoutTime": "12:00"
      }

   c) FAQPage schema — minimum 15 Q&A pairs (critical for AI citation):
      Questions MUST include exact-match keyword phrases such as:
      - "What is an eco retreat in Vietnam?"
      - "Where is the best eco retreat near Ho Chi Minh City?"
      - "How much does glamping in Vietnam cost?"
      - "What makes [Brand] a sustainable resort?"
      - "Is [Brand] good for a weekend nature getaway from Saigon?"
      - "What eco activities are available at [Brand]?"
      - "How far is [Brand] eco retreat from Ho Chi Minh City?"
      Each answer: 60–120 words, authoritative, first-person brand voice,
      includes a related keyword naturally.

   d) BreadcrumbList on all inner pages
   e) Event schema for retreats, workshops, seasonal programs
   f) Review/AggregateRating schema (pull from TripAdvisor/Google reviews)
   g) ImageObject schema on hero images with description + geo

3. CORE WEB VITALS
