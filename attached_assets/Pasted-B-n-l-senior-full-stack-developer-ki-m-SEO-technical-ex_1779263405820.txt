## YÊU CẦU: TẠO CÁC FILE SCHEMA SAU
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### File 1: `lib/schema/organization.ts`
Tạo hàm `getOrganizationSchema()` trả về JSON-LD object gồm:
- @type: ["Organization", "RealEstateAgent", "LocalBusiness"]
- name, url, logo, description, foundingDate
- address (PostalAddress: TP.HCM, VN)
- geo (GeoCoordinates: 10.776920, 106.700981)
- contactPoint (telephone, contactType: "customer service", availableLanguage: "Vietnamese")
- sameAs: LinkedIn, Facebook nếu có
- aggregateRating: ratingValue 4.8, reviewCount 127, bestRating 5
- numberOfEmployees: 15000
- areaServed: ["TP. Hồ Chí Minh", "Đồng Nai", "Bình Dương"]
- knowsAbout: ["Bất động sản", "Định giá AI", "CRM bất động sản"]

### File 2: `lib/schema/website.ts`
Tạo hàm `getWebsiteSchema()` trả về JSON-LD với:
- @type: WebSite
- SearchAction (potentialAction) trỏ về https://sgsland.vn/tim-kiem?q={search_term_string}
- publisher trỏ về Organization @id

### File 3: `lib/schema/realestate-listing.ts`
Tạo hàm `getRealEstateListingSchema(project)` nhận object dự án, trả về:
- @type: RealEstateListing
- name, description, url
- address (PostalAddress đầy đủ)
- geo (GeoCoordinates)
- offers: Offer với price, priceCurrency: "VND", availability
- floorSize: QuantitativeValue (m²)
- numberOfRooms nếu có
- image
- provider: Organization @id

### File 4: `lib/schema/faq.ts`
Tạo hàm `getFAQSchema(items: {question: string, answer: string}[])` trả về:
- @type: FAQPage
- mainEntity: mảng Question với acceptedAnswer

## TÍCH HỢP VÀO CÁC TRANG
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### Trang chủ (`app/page.tsx` hoặc `pages/index.tsx`)
Thêm vào `<head>` hoặc trong component:
```tsx
<SchemaScript schemas={[
  getOrganizationSchema(),
  getWebsiteSchema(),
  getFAQSchema(FAQ_HOMEPAGE),
]} />
```

### Trang dự án (`app/du-an/[slug]/page.tsx`)
Thêm:
```tsx
<SchemaScript schemas={[
  getRealEstateListingSchema(projectData),
  getBreadcrumbSchema([
    { name: "Trang chủ", url: "https://sgsland.vn" },
    { name: "Dự án", url: "https://sgsland.vn/du-an" },
    { name: projectData.name, url: projectData.url },
  ]),
]} />
```

## YÊU CẦU KỸ THUẬT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. **TypeScript** toàn bộ, khai báo interface đầy đủ cho từng schema type
2. Mỗi schema có `@context: "https://schema.org"` và `@id` duy nhất (dùng URL làm ID)
3. Dùng `@id` để reference giữa các schema (Organization → Person, Listing → Organization)
4. Không hardcode string lặp lại — dùng constant `SITE_URL = "https://sgsland.vn"` và `SITE_NAME = "SGS LAND"`
5. Sau khi tạo xong file, chạy lệnh validate:
```bash
   npx schema-dts-gen --check 2>/dev/null || echo "schema-dts not installed, skipping type check"
```
6. Tạo file `__tests__/schema.test.ts` với test cases:
   - Organization schema có đủ required fields (name, url, @type)
   - RealEstateListing schema output hợp lệ JSON
   - FAQ schema đúng cấu trúc mainEntity/acceptedAnswer
   - BreadcrumbList có đúng số item
