```typescript
export interface Article {
  id: string
  slug: string
  title: string
  excerpt: string          // 2-3 câu tóm tắt

  author: string           // author slug
  publishedAt: string      // ISO date
  updatedAt: string
  readTime: number         // phút
  wordCount: number
  tags: string[]
  coverImage: string
  featured: boolean
  outline: string[]        // H2/H3 sections
  sources: Source[]        // Nguồn tham khảo uy tín
  relatedSlugs: string[]
  seo: {
    metaTitle: string      // ≤60 chars
    metaDescription: string // ≤160 chars
    focusKeyword: string
    secondaryKeywords: string[]
  }
}

interface Source {
  name: string             // "Bộ Xây dựng", "Vinhomes", "CafeLand"
  url: string
  publishedYear: number
  type: 'official' | 'news' | 'research' | 'legal'
}
```

### `components/content/AuthorCard.tsx`
Component hiển thị thông tin tác giả — QUAN TRỌNG cho E-E-A-T:
- Avatar tròn (ảnh thật hoặc placeholder với initials)
- Tên + chức danh
- Badge credentials (ví dụ: "5+ năm kinh nghiệm", "Chuyên gia pháp lý")

- Link LinkedIn (opens new tab)
- Số bài đã viết
- Hai biến thể: `variant="inline"` (trong bài viết) và `variant="full"` (trang tác giả)

         [LinkedIn ↗]  •  12 bài viết

## YÊU CẦU KỸ THUẬT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. TypeScript strict, interface đầy đủ cho mọi data type
2. Tất cả dates dùng ISO 8601 format
3. Mọi component nhận className prop cho flexibility
4. `ArticleSchema` dùng `dangerouslySetInnerHTML` — sanitize JSON.stringify output
5. Author avatar fallback: hiển thị initials nếu không có ảnh
