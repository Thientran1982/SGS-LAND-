---
name: Sequence journey design
description: Durable rules for the default customer-care and traffic sequence set.
---

Default sequence journeys should be separated by lead stage: one primary journey per trigger stage, with explicit content links for marketplace, projects, and news. Keep newly seeded journeys inactive until an administrator reviews consent, audience, and copy.

**Why:** Multiple active sequences on the same trigger can send overlapping messages, while purely sales-focused sequences miss retention and useful site traffic opportunities.

**How to apply:** Use stage-specific triggers for welcome, nurture, qualified-investor, proposal, negotiation, lost/reactivation, and won/retention journeys; keep the content in the recipient’s language and include a clear next action.
