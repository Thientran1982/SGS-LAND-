---
name: Dashboard color direction
description: The established color preference for the SGS LAND CRM Overview redesign
---

Keep the existing SGS LAND Overview palette unchanged when restructuring the Dashboard. The current colors are considered clean, simple, and appropriate; design effort should go into hierarchy, guidance, spacing, and task flow rather than a new visual palette.

The sidebar is part of the secondary surface system, not a separate dark brand surface. A redesign must also preserve every existing Overview information group and metric; it may reorganize or progressively stack them, but must not silently remove them.

**Why:** The user explicitly confirmed that the existing Overview colors fit the product, the sidebar should match the secondary surface, and complete information visibility matters more than a compact scorecard.

**How to apply:** Preserve the existing semantic color tokens in production Dashboard work and treat any alternate palette as a temporary exploration only, not an approved direction.
